⚠️ Firebase Rules Setup Required

Online sync কাজ করছে না কারণ Firebase rules set করা হয়নি। নিচের steps follow করুন:

  1. Firebase Console → console.firebase.google.com এ যান
  2. Realtime Database → Rules tab এ ক্লিক করুন
  3. নিচের code টি paste করুন এবং Publish করুন:
{ "rules": { ".read": true, ".write": true } }

⚠️ এটি সকলের জন্য open করে দেবে। যদি শুধু আপনি ব্যবহার করেন তাহলে এটি safe।
